# SSH Key Manager 1.2.0

## Highlights

- Adds a local fingerprint-to-identity registry.
- Adds `skm access matrix` for observed authorization across saved machines.
- Adds `skm audit` for unknown, retired, duplicate, and unsafe SSH trust state.
- Sanitizes terminal control characters from public-key comments before display.
- Detects duplicate local public identities and `.pub` symlinks.
- Detects broad `Host *` blocks that set `IdentityFile`.
- Keeps all identity metadata local and all private keys on their source devices.

See [Identity registry and trust audit](identity-registry.md) for the full model and command reference.
