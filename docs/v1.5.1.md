# SSH Key Manager v1.5.1

Version 1.5.1 is a focused permissions-hardening patch for existing installations.

## Fixed

- SKM now normalizes an existing `~/.config/ssh-key-manager/config` settings file to mode `0600` during runtime initialization.
- The migration is symlink-safe: SKM does not follow a settings-file symlink merely to change permissions on its target.
- A regression test covers both legacy `0644 -> 0600` normalization and symlink-target preservation.

## Upgrade notes

No identity registry, policy, host-trust, or machine configuration migration is required.
After upgrading, `skm doctor` should report `SKM settings permissions: 600` without requiring a manual `chmod`.
